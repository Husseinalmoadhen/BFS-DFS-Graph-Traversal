# BFS and DFS Graph Traversal in C++

## Overview
This project demonstrates graph traversal algorithms using C++.

The program:
- Performs Breadth-First Search (BFS)
- Performs Depth-First Search (DFS)
- Reads graph data from external text files
- Uses adjacency matrices and adjacency lists

---

## Technologies Used

- C++
- STL Vector
- STL Queue
- File Handling
- Makefile
- Linux / g++

---

## Compile

```bash
make
```

## Run

```bash
./graph_traversal
```

---

```text
BFS (Adjacency Matrix): 0 1 2 3 4 5
```
